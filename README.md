# React Native Expo Tesseract.js Demo

![App Screenshot](./screenshot/screenshot.jpg)

A proof-of-concept demonstrating how to successfully run the web-based `tesseract.js` inside a React Native app by bypassing WebView CORS restrictions.

### Installation

```bash
# Install dependencies
npx expo install

# Generate the native project
npx expo prebuild --clear

# Build and run on android
npx expo run:android
